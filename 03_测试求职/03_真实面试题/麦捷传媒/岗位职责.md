# 麦捷传媒软件测试岗位职责

信息来源：招聘 JD 截图、HR 沟通截图及公开招聘信息。截图内容已经转录，未保存临时附件中的个人聊天截图。

## 岗位职责

1. 参与产品需求评审，梳理测试要点并制定测试策略与计划。
2. 设计并执行功能、接口及性能测试用例，精准定位并全程跟踪 Bug 修复。
3. 协助搭建测试环境，配合开发人员排查技术问题，推动质量提升。
4. 整理测试报告并输出结论，参与质量改进方案的制定与落地。

## 任职要求

1. 熟悉黑盒、白盒测试理论，测试流程及各类测试用例设计方法。
2. 熟练使用 Postman、JMeter、Jira 及 Git。
3. 具备数据库基础，能熟练编写 SQL 语句进行查询和校验。
4. 了解 HTTP / HTTPS 协议及自动化测试框架。
5. 对 AI 产品感兴趣。

## 工作时间与福利

- 工作时间：9:30–18:30，周末双休。
- 社会保障：入职即购买五险。
- 其他福利：生日 Party、节庆礼物、入职礼包、周年关怀、不定期下午茶、团建聚餐和年度年会。

> [!warning] 待确认事项

## HR 补充的业务范围

HR 明确说明公司当前涉及：

- 广告投放业务；
- AI 产品测试；
- 自研财务系统。

结合第三方数据核对题，可以推断岗位可能涉及广告平台数据拉取、内部业务数据落库、财务结算和跨系统对账。该结论是基于题型的合理推断，具体系统边界需要在面试中确认。

## 从 JD 翻译出的实际能力要求

| JD 表述 | 面试中可能验证的实际能力 |
| --- | --- |
| 参与需求评审 | 能否发现规则缺失、状态冲突、数据口径不一致和不可测试点 |
| 制定测试策略与计划 | 能否按业务风险确定范围、优先级、环境、数据、时间和准出标准 |
| 功能、接口、性能测试 | 是否同时具备业务测试、接口校验、SQL 对账和基础压测能力 |
| 精准定位 Bug | 能否结合页面、请求响应、日志、数据库、缓存和第三方平台提供证据 |
| 测试环境搭建 | 是否理解配置、账号、数据、依赖服务和环境隔离，而不只是安装工具 |
| 测试报告与质量改进 | 能否说明已测、未测、遗留风险、上线建议和后续改进措施 |
| Postman / JMeter / Jira / Git | 不只会操作界面，还要能解释其在完整测试流程中的作用 |
| SQL 查询和校验 | 能否完成总量、明细、重复、缺失、差异和跨表一致性核对 |
| AI 产品兴趣 | 能否说明非确定性输出、评测集、人工审核、安全和稳定性测试思路 |

## 面试前建议确认的问题

1. 广告投放、财务系统和 AI 产品大约各占多少工作量？
2. 测试团队有多少人，当前岗位是否需要独立负责某条产品线？
3. 第三方广告数据通过实时回调、定时拉取还是两者结合？
4. 当前自动化和性能测试做到什么程度，入职后最希望解决的问题是什么？
5. 发布频率、测试环境数量和上线后的监控、补偿机制是什么？
6. 劳动合同、社保、公积金的主体和缴纳规则是什么？
