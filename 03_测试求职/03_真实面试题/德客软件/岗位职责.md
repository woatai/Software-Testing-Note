# 德客软件 AI 辅助测试工程师岗位职责

信息来源：招聘 JD 截图、[德客软件官网](http://www.dekesoft.com/#/)

## 岗位职责

### 1. 功能测试执行

- 根据需求文档和产品设计，编写测试用例并执行功能测试。
- 覆盖正常流程、边界值、异常场景，输出测试报告。
- 使用缺陷管理工具（如 Jira / 禅道）提交并跟踪 Bug 直至关闭。

### 2. AI 辅助测试（本岗位的核心差异点）

- 使用 AI 工具辅助编写和优化测试用例，提升用例设计效率。
- 使用 AI 工具协助定位缺陷、分析日志、复现问题。
- 探索用 AI 做测试数据的批量生成与清洗。
- 将 AI 提效的方法沉淀成团队可复用的流程（重要）。

### 3. 接口测试

- 使用 Postman / Apifox 等工具做接口功能测试。
- 验证接口的参数校验、异常返回、数据一致性。

### 4. UI 自动化测试协作

- 配合开发搭建 Playwright MCP 环境（有指引文档）。
- 用自然语言描述测试需求，借助 AI 完成浏览器操作测试。
- 记录 AI 生成的测试流程，协助固化为可回归的脚本。

## 任职要求

### 1. 测试基础

- 熟悉软件测试理论：测试用例设计方法（等价类、边界值、场景法）。
- 熟悉缺陷生命周期管理流程。
- 能独立完成一个模块的功能测试。

### 2. 工具使用

- 会用至少一种缺陷管理工具（Jira / 禅道 / 其他）。
- 会用至少一种接口测试工具（Postman / Apifox / 其他）。
- 会基本的 SQL 查询（增删改查、多表关联）。

### 3. AI 工具使用能力（核心要求）

- 日常已经在用 AI 工具工作（如 WorkBuddy、ChatGPT、通义、豆包等）。
- 能清晰地用自然语言向 AI 描述测试需求。
- 理解 AI 的能力边界——知道什么时候不能信 AI 的输出。
- 愿意花时间研究“怎么让 AI 把测试做得更好”。

### 4. 基础技术素养

- 了解 HTTP 协议基础（请求方法、状态码、请求/响应结构）。
- 了解前后端基本交互流程。
- 能看懂简单的代码逻辑。
