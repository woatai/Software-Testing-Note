

## 1. `pd.isna()`：判断缺失值

```
pd.isna(value)
```

作用：判断值是不是缺失值。

常见情况：

```
pd.isna(None)   # True
pd.isna(2)      # False
pd.isna("2")    # False
```

注意：

```
pd.isna("   ")
```

结果是 `False`，因为空格字符串不属于 pandas 的缺失值。

所以项目中又补充了：

```
not value.strip()
```

用于判断：

```
""
"   "
```

---

## 2. 空字符串为什么可以判断真假

Python 中：

```
bool("")
```

结果：

```
False
```

所以：

```
not ""
```

结果：

```
True
```

项目里：

```
not value.strip()
```

就是用来判断字符串去掉空格后是不是空的。

## 4. `Decimal()`：将数字文本转换成 Decimal 数字

```
Decimal("39.9")
Decimal("2")
Decimal("2.0")
```

这些都能成功。

但：

```
Decimal("两件")
Decimal("--")
Decimal("金额待核")
```

会转换失败。

项目中使用：

```
try:
    number = Decimal(text)
except InvalidOperation:
```

表示：

- 能转数字 → 继续处理
    
- 不能转数字 → 保留原值并标记异常
    

---

## 5. `is_finite()`：判断是不是正常有限数字

```
amount.is_finite()
```

正常数字：

```
Decimal("39.9").is_finite()
# True
```

特殊值：

```
Decimal("NaN").is_finite()
Decimal("Infinity").is_finite()
```

结果：

```
False
```

所以即使 `Decimal()` 能转换成功，也还需要判断是不是正常数字。

---

## 6. `to_integral_value()`：判断数量是不是整数

项目代码：

```
if number != number.to_integral_value():
    return float(number), ["数量必须是整数"]
```

作用：

判断数字有没有实际的小数部分。

例如：

```
2.0
```

本质上是整数，所以正常。

```
39.9
```

有小数部分，所以作为“数量”会被标记异常。

项目原则：

```
39.9 不会强制改成 39 或 40
而是保留 39.9，并标记异常
```

---

## 7. `int()`：统一整数类型

```
quantity = int(number)
```

只有确认这个数量本身是整数以后，才转成 `int`。

例如：

```
2.0 → 2
```

这不是强制取整，而是统一数据类型。

---

## 8. `quantize()`：控制金额小数位

```
amount.quantize(Decimal("0.01"))
```

表示保留两位小数。

对应关系：

```
Decimal("0.1")    # 1位小数
Decimal("0.01")   # 2位小数
Decimal("0.001")  # 3位小数
```

例如：

```
Decimal("39.906").quantize(
    Decimal("0.01"),
    rounding=ROUND_HALF_UP
)
```

结果：

```
Decimal("39.91")
```

---

## 9. `ROUND_HALF_UP`：四舍五入规则

```
rounding=ROUND_HALF_UP
```

表示按照传统四舍五入方式处理。

例如：

```
39.904 → 39.90
39.905 → 39.91
```

---

## 10. `enumerate()`：遍历时同时拿到位置和值

```
for position, value in enumerate(orders[column]):
```

例如这一列：

```
[39.9, 20.0, -5]
```

遍历时得到：

```
position = 0, value = 39.9
position = 1, value = 20.0
position = 2, value = -5
```

其中：

```
position
```

表示当前订单的位置。

```
value
```

表示当前字段的值。

---

## 11. `append()` 和 `extend()` 的区别

### append

```
a.append(b)
```

把整个对象放进去。

例如：

```
a = ["数量异常"]
b = ["金额异常"]

a.append(b)
```

结果：

```
[
    "数量异常",
    ["金额异常"]
]
```

### extend

```
a.extend(b)
```

把列表里的元素一个个加入。

结果：

```
[
    "数量异常",
    "金额异常"
]
```

项目中使用：

```
issues[position].extend(field_issues)
```

作用：

把同一条订单的多个异常累积起来。

---

## 12. `issues` 的作用

```
issues = [[] for _ in range(len(orders))]
```

作用：

给每条订单准备一个异常列表。

如果有 3 条订单：

```
[
    [],
    [],
    []
]
```

后续如果第 2 条订单发现两个异常：

```
[
    [],
    ["数量必须大于 0", "实际支付不能为负数"],
    []
]
```

---

## 13. `pd.Series()`：把清洗结果重新写回列

```
orders["数量"] = pd.Series(
    cleaned_quantities,
    index=orders.index,
    dtype="object"
)
```

作用：

把清洗后的：

```
cleaned_quantities
```

重新放回：

```
orders["数量"]
```

其中：

```
index=orders.index
```

表示继续使用原来的订单行索引。

```
dtype="object"
```

表示这一列允许存在多种类型，例如：

```
2
1.5
None
"两件"
```

## 14. 当前数据清洗整体逻辑

```
读取 Excel
↓
判断空值
↓
数量清洗
↓
金额清洗
↓
每条订单收集异常
↓
生成 清洗状态
↓
生成 异常原因
↓
输出 JSON
```

核心原则：

```
能确定的数据 → 自动规范格式
不能确定的数据 → 保留原值
业务不合法的数据 → 标记异常
不删除异常订单
