# 订单系统项目总览

## 项目背景/业务描述

订单系统是电商业务的核心链路，覆盖浏览、加购、下单、支付、发货、收货、完成、评价、取消、退款和售后等流程。

## 核心业务链路

- 浏览商品 -> 加入购物车 -> 提交订单 -> 支付 -> 发货 -> 收货 -> 完成
- 待支付 -> 已支付 -> 待发货 -> 已发货 -> 已完成
- 取消、退款、售后等逆向流程

## 测试范围

- 功能测试：订单创建、状态流转、支付、库存、售后、评价
- 接口测试：下单接口、订单查询接口、支付回调接口、售后接口
- 性能测试：下单、支付回调、抢券等高频接口
- 安全测试：订单查看权限、金额篡改、越权访问

## 重点测试点

- 金额、优惠券、库存、订单状态的数据一致性
- 重复提交、重复支付回调、弱网和超时下的幂等性
- 不同角色、不同订单状态下的操作权限
- 售后申请时机、退款金额、库存释放

## 项目痛点/风险点

- 钱、库存、状态流转是最高风险区域
- 第三方支付回调可能延迟、重复或丢失
- 并发下可能出现超卖、重复扣库存或状态跳转异常
- 权限控制不严会导致水平越权查看他人订单
